# Arquivo de sessões

Esta pasta guarda sessões novas em arquivos separados, sem sobrescrever sessões anteriores.

## Nome dos arquivos

Use o padrão `AAAA-MM-DD-assunto-curto.md`, por exemplo:

`2026-10-18-organizacao-do-historico-por-sessoes.md`

Use a data da sessão e um assunto curto que permita identificar o tema.

## Regras

- Preserve todos os arquivos de sessões anteriores.
- Não substitua `../historico.md` pelo conteúdo acumulado de novas sessões.
- Ao retomar o projeto, leia todos os arquivos desta pasta em ordem cronológica, do mais antigo ao mais recente.
- Deixe claro no título e no conteúdo se o arquivo contém uma transcrição integral ou apenas um resumo/checkpoint.
- Não declare um resumo como se fosse uma transcrição completa.
- Atualize `../estado-atual.md` ao final de uma tarefa para registrar o ponto exato de retomada.
