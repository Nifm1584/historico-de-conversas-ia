# Pasta de sessões — modelo

Crie um arquivo por sessão usando `AAAA-MM-DD-assunto-curto.md`.

- Leia todos os arquivos desta pasta em ordem cronológica ao retomar o projeto.
- Preserve arquivos antigos; não sobrescreva uma sessão anterior.
- Não substitua o histórico original `historico.md` por uma compilação nova.
- Identifique claramente se cada arquivo é uma transcrição integral ou um resumo/checkpoint.
- Atualize `../estado-atual.md` ao concluir uma tarefa.
